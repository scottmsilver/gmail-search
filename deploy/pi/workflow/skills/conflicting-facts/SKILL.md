# Conflicting facts

Compare the exact claims in their message bodies and thread context. Track each value with its message ID, author, sent date, and scope. Similar subjects may concern different events or versions; forwarded and quoted passages are not independent confirmations.

A newer message supersedes an older one only when its content and authority support that reading. Look for explicit corrections, cancellations, acceptance, or revised terms. Distinguish a proposal from a decision and a decision from evidence that something happened.

For example, “Let's move to Friday” does not by itself replace an earlier confirmed Thursday meeting. Report Thursday as confirmed and Friday as proposed unless an acceptance or update settles it.

Use targeted searches for the unresolved difference if useful. Return the supported conclusion with source IDs; if the conflict remains, show both claims and the missing evidence. Verification or delegation is optional, and disagreement alone does not require a fixed review cycle.
