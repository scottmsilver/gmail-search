# Source verification

Treat search hits as leads. Read the relevant message body or thread before presenting an exact claim. A snippet may omit a condition, negation, or correction; quoted text can belong to an earlier sender.

Keep the message ID, thread ID when available, sender, sent date, and a short supporting excerpt alongside each material finding. Use actual returned IDs; never fabricate a message link. Separate what a sender explicitly wrote from your inference. An email describing an attachment does not establish the attachment's contents.

For example, a snippet saying “approved the budget” may expand to “If finance signs off, we have approved the budget.” Report the condition and cite that message rather than calling approval final.

Choose direct Gmail tools or `mcpScript` as useful. A focused search is enough when it resolves the question; a task list or verifier agent is optional. If evidence is missing, state precisely what remains unverified.
